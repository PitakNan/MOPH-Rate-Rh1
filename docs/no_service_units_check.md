# เช็ค "หน่วยบริการที่ไม่มีการให้บริการ" ทุกครั้งที่อัปเดตข้อมูลรอบใหม่

## ทำไมต้องเช็ค

หน่วยบริการบางแห่ง (เช่น สสจ., สสอ.) ไม่มีบริการที่ต้องยื่นราคาเลย ระบบยื่นบัญชีอัตราค่าบริการจะปิดสถานะของหน่วยเหล่านี้เป็น **"6. เสร็จสิ้น (ไม่มีการให้บริการ/รายการราคา)"** แทนการยื่นราคาจริง หน่วยกลุ่มนี้จะไม่มีแถวใน `fact_price.js` (เพราะไม่มีราคาให้บันทึก) ทำให้ถ้าคำนวณ "% ยื่นสะสม" ใน dashboard.html จาก `fact_price.js` อย่างเดียว หน่วยกลุ่มนี้จะถูกนับเป็น "ยังไม่ยื่น" ทั้งที่จริงทำหน้าที่ครบแล้ว — ต้องดึงสถานะนี้จาก Google Sheet มาเสริมทุกครั้ง

## แหล่งข้อมูล

- Google Sheet (ระบบติดตามสถานะยื่นบัญชีอัตราค่าบริการ):
  `https://docs.google.com/spreadsheets/d/19W0_ZEaT_OooAc4PU98E6iI7FOvunrjWs4jg6YPGpwQ/edit?gid=52804694#gid=52804694`
- **คอลัมน์ E = status** (ค่า 0-7 ตรงกับ dropdown สถานะใน admin.html/index.html)
- **status = 6** = "เสร็จสิ้น (ไม่มีการให้บริการ/รายการราคา)" ← ค่าที่ต้องดึงมาใช้
- คอลัมน์ A ของชีท (แม้ header จะเขียนว่า "status" ผิด) คือ **รหัสหน่วยบริการ (HCODE)**

## ขั้นตอนอัปเดต (ทำทุกครั้งที่รีเฟรชข้อมูลรอบใหม่ / build fact_price.js ใหม่)

1. ดึง CSV จากชีท (ต้องแชร์แบบดูได้จาก link):
   ```
   https://docs.google.com/spreadsheets/d/19W0_ZEaT_OooAc4PU98E6iI7FOvunrjWs4jg6YPGpwQ/export?format=csv&gid=52804694
   ```
2. กรองแถวที่คอลัมน์ E (status) = `6`
3. ดึงรหัสหน่วยบริการ (คอลัมน์ A) ของแถวที่กรองได้ทั้งหมด
4. เขียนทับไฟล์ `data/no_service_hcodes.js` เป็น array ของ HCODE เหล่านั้น (ดูรูปแบบไฟล์เดิมเป็นตัวอย่าง)
5. Bump เลข `?v=` ของ `<script src="data/no_service_hcodes.js?v=...">` ใน `dashboard.html` ให้เป็นเวลาปัจจุบัน (กัน browser cache ค้าง)
6. Commit + push แล้วเช็คบน live URL ว่าตัวเลขคอลัมน์ "ไม่มีบริการ" ในตาราง สถิติรายจังหวัด/สถิติรายระดับหน่วยบริการ เปลี่ยนตามจริง

## สูตรที่ใช้ในตอนนี้ (dashboard.html)

ตาราง **สถิติรายจังหวัด** และ **สถิติรายระดับหน่วยบริการ** มีคอลัมน์ "ไม่มีบริการ" แทรกก่อนคอลัมน์ "ยื่น 1/2568" และค่านี้ถูกนับรวมเข้าไปในสูตร % ยื่นสะสมด้วย:

```
% ยื่นสะสม = (ไม่มีบริการ + ยื่น 1/2568 + ยื่น 1/2569 + ยื่น 2/2569) ÷ รพ.ทั้งหมด (ในจังหวัด/ระดับนั้นเอง)
```

หมายเหตุ: ชีทนี้เก็บสถานะ "ไม่มีบริการ" เป็นภาพรวมล่าสุดของหน่วย ไม่ได้แยกว่าเกิดกับรอบไหน (1/2568, 1/2569, 2/2569) — จึงถูกนับรวมเข้า "ยื่นสะสม" แบบครั้งเดียว (ไม่คูณ 3 ตามจำนวนรอบ) ตามที่ CFO ตัดสินใจ (2026-07-22)

## ข้อควรระวังที่เจอระหว่างทำ (2026-07-22)

- ชีทต้นทางมี HCODE ซ้ำอยู่ 1 ตัว: `10717` ถูกใช้ทั้งกับ "โรงพยาบาลพะเยา" และ "โรงพยาบาลสันทราย" (ที่ถูกต้องคือ `11130`) — ตอนดึงข้อมูลควรเช็คโค้ดซ้ำแบบนี้ด้วยทุกครั้ง เพราะจะทำให้ map เข้า `dim_hospital.js` ผิดหน่วย
- ตอนดึงเมื่อ 2026-07-22 ชีทมี 741 แถว, status=6 มี 131 แห่ง ทั้งหมด map เข้า `dim_hospital.js` (762 หน่วย) ได้ครบ ไม่มีรหัสที่ map ไม่เจอ — ถ้าตรวจรอบถัดไปแล้ว map ไม่ครบ ให้แจ้งเตือนก่อนดำเนินการต่อ
